# Pratham Kode - Technical Portfolio

A professional collection of projects and experiments in **cybersecurity**, **blockchain development**, **IoT systems**, and **systems engineering**.

## Technical Skills & Technologies

- **Languages:** Python, JavaScript, Solidity, C++, Rust
- **Blockchain:** Ethereum, Smart Contracts, DeFi protocols
- **IoT & Embedded:** Arduino, Raspberry Pi, embedded systems
- **DevOps & Infrastructure:** Docker, CI/CD pipelines, Linux
- **Security:** Penetration testing, vulnerability analysis, threat assessment

## Project Categories

- **Cybersecurity** - Penetration testing, vulnerability analysis, and threat mitigation
- **Blockchain Development** - Smart contract audits, consensus mechanisms, and DeFi protocols
- **IoT Systems** - Embedded systems, wireless protocols, and sensor networks
- **DevOps & Tooling** - Docker deployments, CI/CD pipelines, and cloud infrastructure

## Quick Start

1. Clone the repository:

```bash
git clone https://github.com/kodepratham/your-repo.git
cd your-repo
```

2. Explore the project directories:
   - `projects/` - Standalone demos and exercises
   - `contracts/` - Smart contract examples and tests
   - `hardware/` - Arduino and Raspberry Pi sketches
   - `tools/` - Utility scripts and tooling

3. Each project contains its own README with specific setup and run instructions.

## Project Structure

```
├── projects/       # Standalone demos and learning exercises
├── contracts/      # Smart contract examples and audits
├── hardware/       # Embedded systems and IoT projects
└── tools/          # Scripts and utilities
```
